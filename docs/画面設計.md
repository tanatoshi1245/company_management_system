# 画面設計（ルート・URL 状態・コンポーネント）

ルータは `src/app/router.tsx`（History API、React.lazy でルートごとに 1 チャンク）。状態は URL に持ち、戻る・リロード・共有で復元する。計算（スコア・絞り込み・並べ替え）はブラウザ側（`src/shared/metrics/`）で、モード切替や絞り込みで再取得しない。

| ルート | 画面 | URL 状態（既定値は URL から消える） | API |
|---|---|---|---|
| `/` | ホーム（契約企業ボード） | `month`, `mine=1`, `industry=a,b`, `type=a,b`, `ending=30\|60\|90`, `status=alert\|watch\|good`, `state=current\|all`, `bench=industry\|target`, `sort`, `q` | `/api/board?month=` |
| `/companies/:id` | 企業詳細 | `month`, `tab=scout\|application`, `attr=<attribute_type>` | `/api/companies/:id?month=` |
| `/targets` | 目標一覧 | `month`, `mine=1`, `missing=1`, `q`, `sort=name\|updated\|progress` | `/api/board`, `/api/targets?month=`, `/api/settings/plan-defaults` |
| `/targets/:id` | 月別目標フォーム + 企業設定 + 変更履歴 | `from=YYYY-MM`（グリッド開始月 − 1 から 12 か月）、`#settings` | `/api/companies/:id`, `/api/companies/:id/targets`, `…/history`, `/api/settings/plan-defaults` |
| `/settings` | 設定（鮮度・Worker 設定の有無・プラン既定値・担当上書き一覧・キャッシュ） | — | `/api/meta`, `/api/health`, `/api/settings/*` |
| `/help` | 指標の定義と注意事項 | `#metric-<key>` / `#derived-<key>` / `#caveat-<id>` | `/api/meta`（caveats） |

## 共通レイアウト

- `AppShell` + `LeftRail`（ロゴ・ナビ 4 項目・データの鮮度・ログイン中のメール・ログアウト）。本文は最大幅 1,440px。
- `PageHeader`（題・文脈行・右上の操作）。`Notice` は error（role=alert）/ warn / info。`Skeleton` は面色の 1.2 秒パルス。
- 色はデータにだけ使う（順序 `--seq-*`、発散 `--heat-*`、状態色はラベル併記）。アクセントはネイビー `#000066`、ゴールドはフォーカスリングとアクティブナビのみ。`prefers-reduced-motion` で動きは 0。

## ホーム `/`（features/home）

1. **PageHeader**: `契約企業ボード`、`2026年10月（営業日 17/21 経過・81%）・データは 10/22 まで・マート更新 10/23 07:52`、右に **業界比 | 目標比**（Segmented）と「最新に更新」。
2. **KpiStrip**（6 タイル）: 契約企業数 / **スカウト消化率**（Σ月間送信 ÷ Σ月間送信枠、枠のある契約企業）/ **スカウト利用率**（1 件以上送信した企業数 ÷ 契約中の企業数）/ スカウト消化ペース遅れ / 14 日以上ログインなし / 契約終了 60 日以内。クリックで該当フィルタ・並べ替え。
3. **BoardFilterBar**（sticky）: 担当=自分（件数付き）・**CS 担当（苗字・複数選択、URL `owner=`）**・業種・種別（直接 / 紹介 / 派遣 / RPO / DA）・契約終了まで・状態・検索・月・並べ替え・クリア。
4. **CompanyBoard**（企業 × 実績）: 左固定列 = 企業名、担当のアイコン + **苗字**、種別チップ、契約タイムライン（`TimelineBar`）、ヘルス色の左罫線。列 = 掲載 / 枠（分数）・閲覧・応募・送信 / 枠（分数、ペース印）・返信（当月。返信月軸）・選考中・採用・最終ログイン（日付 + n 日前）・契約残（日数）。基準がある列（掲載、閲覧、応募、送信、採用、ログイン）は `HeatCell` の 5 段階色、それ以外は数値だけ。行クリックで詳細、ホバー 150ms で詳細を prefetch。
5. **BoardLegend**: モード別の凡例とデータなしの斜線、当月の注記。
6. 空状態 `EmptyBoard`（フィルタのクリア）。

## 企業詳細 `/companies/:id`（features/company）

`CompanyHeader`（名前・状態・種別・業種・プラン・ID、担当 CS + 「変更」→ `/targets/:id#settings`、営業担当、SF 契約、最終ログイン、`TimelineBar`、月セレクタ）→ `UtilizationPanel`（`Bullet` × 2: 塗り = 実績、縦の印 = 期待値、▼ = 業界中央値。`CumulativeChart` × 2: 当月 vs 前月の月内累積）→ `TrendPanel`（`SmallMultiples` 8 パネル: 実数 6 本 + 目標の破線、消化率・返信率 + 業界 p25〜p75 の帯。「表で見る」）→ `ScoutTargetPanel`（属性タブ 11 種、`AttributeBars`）/ `CohortPanel`（`CohortMatrix`、スカウト = 興味あり返信月 / 応募 = 応募月）→ `TargetVsActualPanel`（目標・期待・実績・達成率・進捗バー、「目標を編集」）→ `CaveatFootnotes`。

## 目標 `/targets`・`/targets/:id`（features/targets）

- 一覧: `Chip`（担当=自分・未設定のみ）+ 検索 + 並べ替え。表 = 企業・プラン・担当・目標 5 項目・`TargetProgressBar` × 2（スカウト送信・応募）・最終更新。右上に「プラン既定値で未設定を埋める」（`BulkDefaultsDialog`、verified のみ）。
- フォーム: `MonthGridForm`（12 か月 × 8 行 + 備考。dirty な列は金色、不正値は赤枠、Enter で確定、列ごとに「前月からコピー」）、「プラン既定値を適用」、`save-bar`（未保存 n か月のバッジ・差分を保存・元に戻す）、`CompanySettingsForm`（担当上書き・枠の期間・枠の上書き・メモ）、`ChangeHistory`（監査ログ 30 件）。未保存のまま閉じると `beforeunload` の確認。

## 設定 `/settings`・ヘルプ `/help`（features/settings）

- 設定: データの鮮度 / Worker の設定の有無（真偽値のみ）+ `CacheBumpButton` / `PlanDefaultsEditor`（行 = プラン、列 = 8 指標、行ごとに保存）/ `OwnerOverrideList`。
- ヘルプ: `DefinitionsList`（`METRICS` と `DERIVED_DEFINITIONS` から生成）+ データの注意点（`/api/meta.caveats`）。

## チャート部品（`src/app/components/charts/`）

| 部品 | 用途 | 規約 |
|---|---|---|
| Sparkline | KPI タイルの 13 か月 | 1 色、最終点を直接ラベル |
| HeatCell | ボードのセル | 5 段階発散色 + 右寄せ数値 + 副情報、基準なしは斜線 |
| TimelineBar | 契約期間 | 細線 + 今日印 + 残日数 |
| Bullet | 枠に対する消化 | 塗り / 期待値の印 / 業界中央値の ▼、ペース判定はラベル併記 |
| CumulativeChart | 月内累積（当月 vs 前月） | 2 本線 + 枠の点線 |
| SmallMultiples | 13 か月推移 | 当月は点線、目標は破線、帯は p25〜p75、ツールチップは `<title>` |
| CohortMatrix | コホート × ステータス | 行合計と採用転換率、セルは順序色 |
| AttributeBars | 属性の構成比 | 横棒 + 興味あり率、5 件未満は「少数」 |
