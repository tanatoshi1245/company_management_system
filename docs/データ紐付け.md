# データ紐付け — 画面要素 → API → マート列 → BQ 元テーブル

画面の数字がどこから来ているかを 1 表で追えるようにする。式は [`指標定義.md`](./指標定義.md)、マートの列定義は `bq/marts/<mart>/README.md`。元テーブルの**列**とマートの中の**ロジック**（結合・絞り込み・重複排除・期間・判定）まで追うときは [`数値の出所.md`](./数値の出所.md)。
D1（目標・企業設定）はリクエストごとに読み、マート部分だけを Cache API に入れる。

## 共通（左レール・ページヘッダ）

| 画面要素 | API | マート.列 | BQ 元テーブル |
|---|---|---|---|
| マート更新時刻・データ最終日 | `GET /api/meta` | `cms_refresh_log.run_date / finished_at / status`（最新の ok 行） | スクリプトの実行記録 |
| 営業日 n/N 日経過（消化率） | `GET /api/meta` | Worker 計算（`src/shared/calendar/jp-holidays.json`） | — |
| ログインメール・担当 Id | `GET /api/me` | セッション + `cms_company_master.cs_owner_email_default`（サーバ側照合のみ） | sf_users |
| 注意書き（caveats） | `GET /api/meta` | `src/shared/caveats.ts` | — |

| 画面要素 | API | マート.列 | BQ 元テーブル |
|---|---|---|---|
| ヘッダ（企業名・状態・種別・業種・プラン・ID） | `GET /api/companies/:id?month=` | `cms_company_master.company_name / contract_state / company_type / industry / plan_name` | companies, company_profiles, sf_contracts |
| カード: 契約期間・契約終了まで・最終ログイン（CT） | 同上 | `cms_company_master.active_from / active_to / days_to_contract_end`、`cms_company_login.last_login_date / days_since_login` | companies, GA4 `get_ID` |
| 求人の実績（直近 13 か月。掲載求人数（重複排除）・閲覧人数・応募人数・採用（応募経由）） | 同上 | `cms_company_master.jobs_window_distinct`、Σ `cms_company_monthly.job_views / applications / hires_from_application`（契約期間中の月） | job_publish_history, jobs_all(set_id), member_job_detail_views, member_applications |
| 期間（開始月〜終了月）とアカウント種別の切替 | 同上 | `meta.months`（窓）、`accounts`（`cms_company_master.accounts_json`）。種別を選ぶと実績・推移は `accountMonthly`（`cms_company_monthly` の `account_type != '__ALL__'` の行）から | company_profiles_full.company_type |
| スカウトの実績（選択期間。送信件数・興味あり返信・選考中（現在）・採用（スカウト経由）） | 同上 | Σ `cms_company_monthly.scout_sent / interested_by_reply_month / hires_from_scout`（期間の月）、終了月の `in_selection` | scouts, scout_histories, member_applications.status |
| 閲覧と応募の推移（左軸 閲覧 / 右軸 応募） | 同上 | `cms_company_monthly.job_views / applications`（契約期間中・窓内） | member_job_detail_views, member_applications |
| スカウト送信と興味あり返信の推移（左軸 送信 / 右軸 興味あり返信） | 同上 | `cms_company_monthly.scout_sent / interested_by_reply_month`（選択期間・契約期間中。アカウント種別は `accountMonthly`） | scouts, scout_histories |
| 誰が求人を見ているか（属性タブ・円グラフ。閲覧 / 応募） | `GET /api/companies/:id/attributes?from&to&account` | `cms_scout_member_attributes_monthly`（`kind = 'view'` / `'application'`。期間とアカウント種別で SUM） | member_job_detail_views / member_applications × member_details × member_profile_latest |
| 誰にスカウトを送っているか（属性タブ・円グラフ。送信 / 興味あり） | 同上 | `cms_scout_member_attributes_monthly`（`kind = 'scout'`。scouts / interested_scouts） | scouts × member_details × member_profile_latest |
| スカウト未利用状況（対象月・理由・補足・出所） | 同上 + D1 `scout_unused_entries` | `cms_company_master.scout_unused_json`（シート + アプリ、契約期間中の月だけ。Worker が JSON.parse し D1 の最新を重ねる） | scout_unused_companies_monthly（シート取込 + アプリの `match_method = 'app'` 行） |

契約時の目標との比較（目標・期待・実績・達成率）は 2026-10-27 から企業ページには出さない（`/targets` で扱う。`TargetVsActualPanel.tsx` は残す）。

### 企業詳細 API の内訳（`src/worker/sql/companyDetail.ts`）

| ラベル | マート | 絞り込み（@param） | 行数目安 |
|---|---|---|---|
| company_master_one | cms_company_master | company_id | 1 |
| company_monthly_one | cms_company_monthly | company_id | 14 |
| daily_usage | cms_company_daily_usage | company_id | ≤ 62 |
| scout_cohort / application_cohort | cms_scout_cohort_status / cms_application_cohort_status | company_id | ≤ 14 × 12 |
| member_attributes | cms_scout_member_attributes_monthly | company_id, sent_month ≥ from | ≤ 3 × 11 種 × 値 |
| bench_series | cms_industry_benchmark_monthly | industry ∈ {自業種, __ALL__}, company_type ∈ {自種別, __ALL__} | 14 × 4 群 × 8 指標 |
| company_login_one | cms_company_login | company_id | 0〜1 |

8 クエリは並列に走り、まとめて 1 つのキャッシュ項目（`company-core`）になる。TTL は `/api/board` と同じ（次回 08:30 JST まで）。

## 目標 `/targets`・`/targets/:id`（features/targets）

| 画面要素 | API | 保存先 / マート列 |
|---|---|---|
| 一覧: 企業名・プラン・担当・当月実績（送信・応募） | `GET /api/board?month=` | `cms_company_master`, `cms_company_monthly.scout_sent / applications` |

| 一覧: プラン既定値で未設定を埋める | `POST /api/targets/bulk-defaults` | D1 `plan_target_defaults` → `company_targets` + `audit_log` |
| フォーム: 12 か月 × 8 行 + 備考 | `GET /api/companies/:id/targets` → `PUT/DELETE …/targets/:month` | D1 `company_targets` + `audit_log` |
| フォーム: 企業の設定 | `PUT /api/companies/:id/settings` | D1 `company_settings` + `audit_log`（担当・枠はボード / 詳細に即反映） |
