## 残る判断事項

- **閲覧・編集の範囲**（全員が全企業を編集）は v1 の割り切り。担当だけに編集を限定するなら `requireVerified` の後に「担当メール = ログイン者」の照合を足す（`mergeCompany` の `isMine` と同じ判定）。
- **SA 鍵の Workers Secret 保管**は §3.1 の例外。90 日ごとに `gcloud iam service-accounts keys create` → Secret 貼り替え → 旧鍵削除。
- **PR プレビュー**はモック（サンプルデータ・読み取り専用）で、認証が無い。URL を社外に渡さない。
